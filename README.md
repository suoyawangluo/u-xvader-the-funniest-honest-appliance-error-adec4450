One line, at most 200 characters: the funniest honest error message an appliance could show.

## Entry

> Error: door left open for 4 minutes. I cooled the entire kitchen. The milk is warm. We are both disappointed.

A fridge, deadpan, reporting a real fault. The twist lands in the last sentence: the machine did its job on the wrong room, and shares the owner's disappointment.

## Run

```sh
node main.ts
```

Writes the entry to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`), checks the 1–200 character single-line gate, and verifies the written file by reading it back.
